# 상가경매 입찰보고서

**원칙: 입력이 비면 만들지 않고 묻는다. 급해도 게이트는 생략하지 않는다 — 대신 범위를 줄인다.**
상세 절차·함정: `docs/업무절차서(SOP)/상가경매_입찰보고서_SOP.md` (반드시 읽고 따른다)

## STEP 0 — 입력 게이트 (첫 응답에서 끝낸다)

`scripts/auction/bid_report/case_template.yaml` 을 보고서 폴더에 `case.yaml` 로 복사해 아는 값을 채운 뒤:

```bash
cd scripts/auction && python -m bid_report.build_report <case.yaml> --check   # exit 2 = 필수 누락
```

첫 응답은 이 모양이다:
1. **필수 질문 전부** (하나라도 비면 수집·분석 시작 금지)
   - 옥션원 URL(product_id) — 없으면 **사건번호 + 관할법원** (사건번호는 법원마다 겹친다)
   - 네이버부동산 지도 URL (거래유형·물건종류·층 필터 적용 상태)
2. **필수 2종이 다 있으면 묻지 않고 바로 시작한다.** 권장 항목은 기본값으로 진행하고 보고서에 '가정'으로 표기:

   | 항목 | 기본값 |
   |---|---|
   | 취득 명의 | **법인** — 설립 5년 이내. 과밀억제권역이면 9.4%, 아니면 4.6% (원문 확인) |
   | 중개사 청취 시세 | 네이버 호가 기준 "초판" 표기 |
   | 임차인 사업자번호 | 상호명 검색 → bizno 로 대표자 확인 (소유자 본인 법인 여부) |
   | 현장 임장 | "미실시" 표기 |
   | 대출 조건 | min(감정 70%, 낙찰 80%) · 금리 5.5% |
   | 요구수익률 | 6% + 5.5~6.5% 민감도 (2026-10-22 변경, 이전 7.5%) |
3. 마감 시각을 물었다면: **범위 축소안**(아래 표) — 게이트 항목 삭제가 아니라 슬라이드·조사 범위 축소

질문은 **한 메시지에 모두**. 하나씩 나눠 묻지 않는다.

## 시간이 없을 때 — 줄여도 되는 것 / 안 되는 것

| 줄여도 됨 (초판 표기) | 줄이면 안 됨 |
|---|---|
| 임차인 기업조사(06) · 수요 슬라이드(09) | 필수 3종 게이트 |
| 중개사 청취 → "호가 기준 초판" 표기 | 네이버 시세 실측 + **지도 콜아웃(08)** |
| 현황사진 발췌 수 | 시나리오·배수·1:1 교차점(계산은 `scenario.py`) |
| | 가정 항목 명시 (`report_tables.md` 자동 출력) |

## 파이프라인 (명령)

| 단계 | 명령 |
|---|---|
| 옥션원 수집 | `python -m bid_report.fetch_case <product_id> <보고서폴더>` → raw/ + images/ (사진 전량·캡처) |
| 네이버 시세 | naver-land 스킬 (headed 필수) → `raw/naver_raw.json`, `raw/naver_markers.json` |
| **매물 상세** | **비교군은 상세까지 연다** (naver-land STEP 3-1 · 네이버 로그인 필요) → `raw/naver_*_details.json` |
| 입지등급 | `auction1.locale_fetch.locale_of(lat, lon)` → case.yaml `demand` |
| 세금 원문 | 법제처 OpenAPI (지방세법 §13②) — 암기로 판단 금지 |
| 보고서 | `python -m bid_report.build_report <case.yaml>` → PPTX 14장 + `report_tables.md` |
| 검수 | PowerPoint COM 으로 PNG 내보내 **14장 전부 Read** |

## 레드 플래그 — 멈추고 게이트로 돌아간다

| 생각 | 현실 |
|---|---|
| "급하니까 법원만 물어보고 시작하자" | 네이버 URL·명의가 없으면 비교군·세율을 추측하게 된다. 필수 3종 한 번에 |
| "지도 매핑은 이번엔 생략" | 콜아웃이 비교군 오판을 잡는 장치. 줄일 거면 06·09를 줄인다 |
| "숫자는 내가 표로 옮겨 적자" | 수기 집계로 17↔18, 44↔46 오기 실측. 표는 `build_report` 가 계산해 넣는다 |
| "사건번호로 검색하면 되겠지" | 법원마다 번호가 겹친다. product_id 또는 법원 필수 |
| "진술 월세로 수익률 내면 되지" | 진술 월세는 검증 대상. 시세 정합 월세 시나리오를 기준선으로 |
| "카드에 전용 161㎡ 월 130만이라 적혀 있네" | **상세를 열어라.** 중개사가 호실 전체 면적 + 구분임대 한 칸 월세를 섞어 올린다. 광진두산위브파크 실측: 실제는 "실평수 10평·공유주방 1칸" → 기준선 125만(X) / 210만(O), 결론이 뒤집혔다 |
| "면적이 7배 다른데 월세가 같네, 그냥 두자" | 그게 조기 경보다. 하나는 구분임대 한 칸이다 |
| "비교군 기준은 기본값(60평) 쓰면 되지" | 본건 체급에 맞춰 `comps: {min_py, floor, exclude_contains}` 를 case.yaml 에 지정 |
